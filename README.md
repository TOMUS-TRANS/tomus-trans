# Tomuś Trans — strona warsztatu

Statyczna, responsywna strona w języku polskim. Nie wymaga płatnego CMS ani serwera z PHP.

## Pliki
- `index.html` — treść strony
- `style.css` — wygląd i układ na telefonie/komputerze
- `script.js` — menu mobilne i aktualny rok w stopce
- `favicon.svg` — ikona strony

## Podgląd lokalny
Otwórz `index.html` w przeglądarce. Do publikacji w internecie wgraj wszystkie pliki razem.

## Bezpłatna publikacja przez GitHub Pages
1. Zaloguj się lub utwórz konto na https://github.com/
2. Utwórz publiczne repozytorium, np. `tomus-trans`.
3. Wgraj `index.html`, `style.css`, `script.js` i `favicon.svg` do głównego katalogu repozytorium.
4. Wejdź w **Settings → Pages**.
5. W sekcji publikacji wybierz **Deploy from a branch**, branch `main`, folder `/ (root)`, zapisz.
6. Po chwili GitHub pokaże adres strony w rodzaju `https://twoja-nazwa.github.io/tomus-trans/`.

## Przed publikacją koniecznie sprawdź
- Dodaj dokładny adres warsztatu i prawdziwe godziny otwarcia.
- Zdjęcia w nagłówku i sekcji „O warsztacie” są z Unsplash i wymagają internetu; możesz podmienić adresy zdjęć w `style.css` na własne zdjęcia warsztatu.
- Potwierdź, że numer telefonu jest prawidłowy.
- Uzupełnij dane firmy i politykę prywatności, jeśli wdrożysz formularze, analitykę lub inne narzędzia zbierające dane.

## Koszt
Sama strona i hosting GitHub Pages mogą być bezpłatne. Własna domena jest opcjonalna i zwykle płatna. Obecna strona nie zawiera formularza wysyłającego dane — przycisk kontaktu otwiera połączenie telefoniczne.
